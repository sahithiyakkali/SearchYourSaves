# Searchable Saved

A product concept case study: a search layer for Instagram's Saved tab. Static site, no build step — same pattern as your other repos.

## Files
- `index.html` — the whole case study (problem, users, the feature, phone mockups, flow, metrics, risks)
- `styles.css` — styling

## Deploy
1. Create a new GitHub repo (e.g. `searchable-saved`).
2. Upload `index.html`, `styles.css`, and this `README.md` to the repo root.
3. Settings → Pages → Deploy from branch → main → / (root).
4. Live at `https://YOUR-USERNAME.github.io/searchable-saved/`.
