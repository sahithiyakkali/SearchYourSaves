# Searchable Saved

A product concept case study: a search layer for Instagram's Saved tab -> https://sahithiyakkali.github.io/SearchYourSaves/

As an avid Instagram user, I noticed that most users save thousands of posts and can almost never find them again. This is a product concept for fixing that: a search layer for the Saved tab that works entirely on hashtags and keywords in the background — no filter buttons, no setup, just type what you remember. Includes the problem framing, UX decisions, and full-fidelity phone mockups built from my own actual Saved tab.

## Files
- `index.html` — the whole case study (problem, users, the feature, phone mockups, flow, metrics, risks)
- `styles.css` — styling
